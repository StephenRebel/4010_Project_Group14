\section{Introduction}

This work explores training a Reinforcement Learning (RL) agent to generate musical compositions (typically 4 to 16 bars) from scratch. Unlike standard approaches that rely on supervised pre-training, our agent learns purely through interaction with the environment.
The core challenge lies in generating coherent sequences guided only by a scalar reward signal.
Musical quality is multidimensional and reliant upon rhythm, harmony, and structure. As well, it is highly context-dependent, requiring the agent to balance competing objectives over long time horizons.

This problem offers a valuable testbed for sequential decision-making with sparse, delayed rewards. Unlike typical RL problems with clear objective metrics, like game scores, music requires defining a reward function for subjective qualities. Investigating how RL agents learn musicality allows for a direct comparison against traditional deep learning methods and provides insight into long-term dependency problems common in real-world planning systems.

We frame the generation process as a constrained Markov Decision Process (MDP) defined by $(\mathcal{S}, \mathcal{A}, P, R, \gamma)$:

\begin{description}
  \item[State Space ($\mathcal{S}$):] The state $s_t$ represents the musical composition generated up to step $t$. It is encoded as a fixed-length vector containing the indices of generated notes and the number of beats remaining in the current bar.

  \item[Action Space ($\mathcal{A}$):] The action space is discrete, consisting of 90 actions. These represent the constrained set of notes spanning two octaves of the C major scale (MIDI pitch 60 to 84), paired with specific note durations (sixteenth to whole notes) and corresponding rests.

  \item[Transition Function ($P$):] Transitions are deterministic. When an action is selected, the note is appended to the composition. If a selected duration exceeds the remaining beats in the current bar, it is truncated to fit and the agent penalized. The episode terminates when the composition reaches the pre-defined length.

  \item[Reward Function ($R$):] We employ a sparse reward structure. Immediate negative penalties are given when invalid actions are selected. The primary reward for a composition is calculated only at the terminal state. It is a mathematical evaluation of rhythmic consistency, harmonic structure, melodic progression, and repetition. Finally penalties are applied for violations of musical properties.

  \item[Discount Factor ($\gamma$):] Given the finite nature of music composition, we do not discount future rewards, setting $\gamma = 1$.
\end{description}

\section{Approaches}

\subsection{Prior Works}

Traditional methods of music generation often involve supervised learning and deep neural networks like Long short-term memory (LSTM) models \citep{lstm-paper}. \citet{RNN-finetune} applied Deep Q-RL \citep{dqn-paper} finetuning to an LSTM with a reward function derived from music theory heuristics (rhythm, harmony, etc.). Their goal was to circumvent the traditional purely data driven approach and generate monophonic melodies. Similarly, in \textit{Bach2Bach}, \citet{bach2bach} employ a bi-axial LSTM as an initial probabilistic model to which they apply a Deep Q-Learning Network (DQN) RL approach to improve quality.

Other approaches frame music generation as a sequence modeling task, using n-grams \citep{ngram-paper}. N-grams capture local dependencies between notes or chords but struggle to represent long-term and global structure, motivating the use of reinforcement learning and deep neural networks.

A more recent approch discussed by \citet{music-rlhf} employs reinforcement learning from human feedback (RLHF) \citep{rlhf} to a text-to-music autoregressive model. This powerful approach demonstrated significant improvements over their baseline models. \textit{Music Generation using Human-In-The-Loop Reinforcement Learning} \citep{hitlp-paper} is another very recent paper in which the the reseachers apply RLHF to learn music generation. They implement a tabular Q-learning \citep{q-learning} approach in which human raters provide feedback per generation guiding their model to learn subjective human preferences.

Designing an effective reward function is critical to many RL approaches. \citet{rhythm-paper} propose methods to mathematically quantify the desirability of rhythm, repetition, motifs, and transitions, computing global quality from local features such as note timings, onsets, durations, and pattern repetitions. \citet{survey_evaluation_metrics} also go in depth describing how to measure music generated by AI, and define a clear taxonomy. It breaks down evaluation into many subsections, including Symbolic Score Quality Evaluation which involves using rule-based systems to analyse the structure of a composition and assign it a score, among others.

\subsection{General Appraoch}

We evaluate four distinct architectures for music generation. We implement two reinforcement learning agents: Deep Q-Networks (DQN) and Proximal Policy Optimization (PPO), and compare them against N-gram models and LSTM neural networks as baselines. Whiel all approaches operate within the same constrained environment, they each employ different learning methods.

\subsection{Reinforcement Learning Agents}

Our primary focus lies in training RL agents from scratch to generate musical compositions through environmental interaction. We employ the Stable-Baselines3 library~\citep{stable-baselines3} to implement two state-of-the-art RL algorithms.

\subsubsection{Deep Q-Network (DQN)}

DQN is a value-based off-policy algorithm that learns to approximate the action-value function $Q(s, a)$, representing the expected return when taking action $a$ in state $s$ and following the optimal policy thereafter \citep{dqn-paper}. The algorithm maintains two key components: a replay buffer storing past experiences $(s, a, r, s')$ and a target network to stabilize training. The Q-network is updated by minimizing the temporal difference error:
\[
\mathcal{L}(\theta) = \mathbb{E}_{(s,a,r,s') \sim \mathcal{D}}\left[\left(r + \gamma \max_{a'} Q_{\text{target}}(s', a') - Q(s, a; \theta)\right)^2\right]
\]

\subsubsection{Proximal Policy Optimization (PPO)}

PPO is an on-policy actor-critic algorithm that directly learns a parameterized policy $\pi_\theta(a|s)$ while estimating a value function $V(s)$ \citep{ppo-paper}. Unlike DQN, PPO updates the policy using the clipped surrogate objective to prevent destructively large policy updates:
\[
\mathcal{L}^{\text{CLIP}}(\theta) = \mathbb{E}_t\left[\min\left(r_t(\theta)\hat{A}_t, \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon)\hat{A}_t\right)\right]
\]

where $r_t(\theta) = \frac{\pi_\theta(a_t|s_t)}{\pi_{\theta_{\text{old}}}(a_t|s_t)}$ is the probability ratio and $\hat{A}_t$ is the advantage estimate computed using Generalized Advantage Estimation (GAE) with $\lambda = 0.95$.

The hyperparameters we used for both agents are shown in Table~\ref{tab:dqn_ppo_hyperparameters}. These were chosen to try to maximize our average reward, as well as try to produce musically coherent compositions. We use a Multi-Layer Perceptron (MLP) policy network that processes the flattened observation vector (musical score representation plus remaining beats). The agents receive no musical training data and learn purely from the reward signal defined by our multi-faceted reward function.

\subsection{Baseline Methods}

To contextualize the performance of our RL agents, we implement two supervised learning baselines trained on musical data.

\subsubsection{N-gram Language Model}

We adapt the n-gram language modeling approach to musical sequence generation using NLTK's implementation. The model treats musical actions as tokens and learns conditional probability distributions $P(a_t | a_{t-n+1}, \ldots, a_{t-1})$ from a corpus of collected compositions \citep{ngram-site}.
We use a trigram model ($n=3$) with Laplace smoothing to handle unseen action sequences. The vocabulary consists of all 90 possible actions from our action space plus start and end tokens. The training corpus consists of transformed compoisitions from the Nottingham music dataset \citep{nottingham-dataset}.
During generation, the model samples the next action based on the learned conditional probabilities, constrained to select only valid actions given the remaining beats in the current bar. When the model encounters contexts with no learned transitions, it falls back to uniform sampling over valid actions. This approach provides a probabilistic baseline that captures local sequential patterns in musical composition.

\subsubsection{LSTM Neural Network}

Our LSTM baseline employs a recurrent neural network to model longer-term dependencies in musical sequences \citep{lstm-paper}. The architecture consists of an embedding layer mapping action indices to dense vectors (128 dimensions), a single-layer LSTM with 256 hidden units and dropout (0.3), followed by a fully-connected output layer producing logits over the action vocabulary.
The model is trained on the same action sequence dataset using teacher forcing, where at each timestep the model predicts the next action given the previous ground-truth actions. We use cross-entropy loss with padding token masking:
\[
\mathcal{L} = -\sum_{t=1}^{T} \log P(a_t | a_{1:t-1}; \theta)
\]

Due to the variable and often lengthy compositions in the Nottingham MIDI dataset \citep{nottingham-dataset}, we chunk sequences into overlapping segments of 64 actions to facilitate efficient training. The model trains for 20 epochs using Adam optimizer with learning rate $10^{-3}$ and weight decay $10^{-4}$, saving the best model based on validation loss.
For generation, the LSTM autoregressively samples actions, maintaining hidden state across the composition. Like the n-gram model, action selection is constrained to valid durations given bar boundaries. The LSTM's recurrent architecture enables it to capture longer melodic and rhythmic patterns compared to the Markov assumption of n-grams.

\subsection{Reward Function Design}

The reward function serves as the sole learning signal for our RL agents and plays a critical role in shaping compositional quality. We design a multi-component reward function that evaluates four fundamental aspects of musical structure: rhythmic coherence, harmonic correctness, functional chord progression, and repetition of notes and motifs. Each element produces a normalized score in $[0,1]$. After combining these components with their respectful weights, we subtract several global penalties designed to prevent musically nonsensical behavior. This results in a final scalar reward our agent attempts to maximize. 

\subsubsection{Rhythm Reward} The rhythm reward evaluates the temporal organization across the sequence of notes. Each note onset is mapped to a grid of four subdivisions per quarter note, allowing rhythms to be compared independently of their tempo. \citep{rhythm-paper} There are five metrics contribute to this reward component:

\paragraph{Quarter-beat ratio:}
We compute the fraction of notes beginning on strong beats by dividing the number of onsets divisible by 4 over the total number of onsets. We do this to maintain structure while still allowing syncopation. Notes starting on strong beats give the melody a rhythmic grounding, and deviations from the beat allow for more tension.

\paragraph{Inter-onset interval stability (rhythmic regularity):}
Measures spacing between notes. We reward consistent pacing using
variance of IOIs:
\vspace{-4pt}
\[
s_{\text{IOI}} = 1 - \frac{\mathrm{Var}(t_{i+1}-t_i)}{(\mathbb{E}[t_{i+1}-t_i])^2 + \varepsilon}.
\]

\paragraph{Entropy:}
To prevent monotonous or overly chaotic rhythms, we compute the entropy of note placements within a bar. A moderate entropy value corresponds to the level of rhythmic variety typically seen in simple melodies, whereas very low entropy signifies too much rhythmic repetition, and high entropy signals rhythmic noise.

\paragraph{Note density:}
We reward melodies whose amount of notes per bar fall near an expected range, preventing overly sparse or overly
dense rhythms.

\paragraph{Syncopation:}
We target moderate syncopation by rewarding off-beat onsets up to a 20\% rate, with the intentions of influencing expressive accent patterns without destabilizing the whole rhythm.

The final rhythm score is the weighted average of all five metrics using the tuned weights
$(1.8, 1.2, 0.9, 0.8, 1.0)$.

\subsubsection{Harmony Reward}

To evaluate correctness of the harmony, we assign each bar a chord label using a rule-based detector that 
scores candidate chords according to three factors: Pitch content, beat salience, and note duration weighting. Given the detected chord for a bar, each note contributes to the harmony score as follows~\citep{piston2011harmony}:

\begin{itemize}
    \item \textbf{Chord tones} receive a reward of $+2.0$, as these tones establish the harmonic identity of the bar and are important to stabilizing the tone.
    \item \textbf{Diatonic non-chord tones (NCTs)} are classified using intervallic relationships 
    and receive fractional credit depending on their melodic function. Passing, neighbor, and escape tones earn
$+0.5$; appoggiaturas $+0.75$; anticipations $+0.6$; suspensions and retardations $+0.75$ and $+0.65$
respectively. Lastly, pedal tones receive $+0.6$. Rewarding NCTs prevents the agent from overfitting to melodies that are completely chordal, resulting in more expressive and human-like melodic patterns.
\end{itemize}

To prevent chord-heavy bars from negatively influencing the proportions of the total reward, we calculate our total harmony reward as the following:

Let $S_{\text{harmony}}$ denote the sum of all per-note contributions. We normalize using an ideal maximum per-note value of $1.7$:
\vspace{-4pt}
\[
R_{\text{harmony}} = \frac{1}{1.7} \cdot \frac{S_{\text{harmony}}}{\#\text{melodic notes}}
\]

\subsubsection{Progression Reward}

Harmonies that are of basic correctness are not sufficient enough for generating structured and coherent music, 
so the progression reward evaluates how well adjacent bars follow harmony motion in appropriate style~\citep{kostka2017tonal}. \\ The process is as follows: Detect the chord in each bar $b$: $C_b$, map each chord to a functional root to normalize chord qualities, and then finally look up the transition weight $w(C_b \rightarrow C_{b+1})$ describing how strong that motion is.

The final progression score averages these transition weights:
\vspace{-4pt}
\[
R_{\text{progression}} =
\frac{1}{N_{\text{valid}}}
\sum_{b} w(C_b \rightarrow C_{b+1})
\]
where $N_{\text{valid}}$ is the number of valid bar pairs. A valid bar pair means that they have detected chords in the pair. Stronger transitions receive higher weights, meaning there is smooth and coherent movement across bars.

\subsubsection{Repetition Reward}

To achieve motif structure, we flatten the melody into a sequence of $(\text{pitch},\text{duration})$
tokens and compute contiguous $n$-gram motifs for $n\in\{2,3,4\}$. These short fragments model common
melodic motifs without requiring explicit boundaries.

For each $n$ we count motif occurrences and compute:

\paragraph{Meaningful repetition:}
Motifs appearing 2–3 times contribute positively, however motifs that are repeated 4+ times result in penalties to prevent the agent from cheating the reward.

\paragraph{Variety bonus:}
We reward the presence of multiple distinct motifs that repeat:
\vspace{-4pt}
\[
r_{\text{variety}} = 
\min\!\left(0.3 \cdot \frac{|M_{\text{rep}}|}{|M_{\text{all}}|},\, 0.2\right).
\]

\paragraph{Novelty bonus:}
Motifs occurring only once also contribute, balancing repetition with interest.

The final repetition reward is capped:
\vspace{-4pt}
\[
R_{\text{repetition}} = 
\min(r_{\text{motif}} + r_{\text{variety}} + 0.5\, r_{\text{novelty}},\, 0.75).
\]

\subsubsection{Penalties}

Our training revealed several faults including things like long-note exploitation, empty bars, 
and mechanical rhythms. Due to these faults, we decided to introduce auxiliary penalties:

\begin{itemize}
    \item \textbf{Bar monotony}: Penalizes uniform durations within a bar.
    \item \textbf{Early bar quality}: Discourages empty or single-note openings.
    \item \textbf{Long-note exploitation}: Penalizes excessive use of whole notes.
    \item \textbf{Duration variety}: Encourages use of multiple rhythmic values.
    \item \textbf{Structural penalties}: Discourage weak endings and empty mid-piece bars.
\end{itemize}

\subsubsection{Final Combination}

All reward component scores are normalized to $[0,1]$ and combined as:\\
\vspace{-4pt}
\[
R_{\text{final}} = \max\left( 0,\, [0.45\,R_{\text{rhythm}} +
0.22\,R_{\text{harmony}} +
0.18\,R_{\text{progression}} +
0.15\,R_{\text{repetition}}] - \text{TotalPenalty} \right)
\]

The weights were selected specifically to reflect the importance of each musical dimension relative to each other, with rhythm emphasized due to its strong influence on how music is perceived.

This design reflects a broader challenge in applying RL to a domain that relies on creativity rather than simple logic. Having to formalize subjective musical criteria into objectives that we could quantify and have remain learnable was difficult to formulate. Our approach to our reward balances the structure of music theory with elements on tuning, to receive coherent and consistent compositions in terms of melody, harmony, rhythm, and expression.

\section{Empirical Studies}

Each model was trained using multiple random seeds to account for variance in the learning process. Training stability was monitored through episodic rewards, and the final policies were assessed based on the quality of generated sequences. This comparative analysis examines the differences between both the proposed RL agents and the baseline methods.

We validate our reward function's calibration by testing it on four well known melodies which were manually encoded in our environment: "Twinkle Twinkle Little Star", "Itsy Bitsy Spider", "Ode to Joy", and "Happy Birthday".

We tested the PPO agent against different hyperparameter configurations, as shown in Table ~\ref{tab:ppo_ablation}. In most of the sets, the final average reward varies slightly, however, when looking at the actual music compositions, there are pretty big differences. For example, set A prefers using a lot of 8th notes, and sounds pretty groovy. Set B in contrast, pretty much only uses the same 4 notes in a very repetitive and monotone way. Even though Set B achieves a higher average reward, Set A is more musically pleasant to the ear.

\section{Conclusion}

\subsection{Method Outcomes}

We have had some success in designing an environment and reward function capable of a guiding RL agents to learn a policy for the generation of constrained musical compositions. Our PPO agent succeeds in learning a high reward policy however the quality of the compositions as evaluated by human listeners is still not very high. DQN fails entirely to learn, and comparing against supervised baselines LSTSM generation was as successful and pleasing to humans if not exceeding our RL methods. We have discovered that the final quality relies heavily upon the reward function and as such its design is crucial to the outcome. It is very challenging to completely capture and describe ideal musical structure across its many dimensions in a purely mathematical formula.

\subsection{Future Recommendations}

We recommend future research perform a deeper investigation of the possibility of expressing musical quality mathematically and to focus on actor-critic algorithms like PPO over DQN and other off-policy algorithms. We believe it may be of value to focus reward formulas as particular dimensions of musicality, harmony, rhythm, etc. rather than attempting to represent them all in one reward. Additionally we are interested in exploring the application of Reinforcement Learning from Human Feedback to music generation \citep{music-rlhf}, and its use in improving existing supervised and unsupervised learning methods as demonstrated in our baselines and widely supported in existing literature.
